# Backgrounds

Export these from the Figma file (`chers-design-app`) at 1x and drop them here:

| file          | Figma source                        | used by                    |
|---------------|-------------------------------------|----------------------------|
| `leopard.png` | `background 01` — lilac leopard     | home, closet, saved, add-* |
| `hangers.png` | `loading img - animate` — neon rail | aesthetic picker           |
| `avatar.png`  | `image 1` — the helper portrait     | every dialogue bar         |

`app.css` sets a flat fallback colour behind each, so the UI is usable before
the artwork lands.
